# Controle de Estoque - Farmácia

Sistema frontend para gerenciamento de estoque de medicamentos, com interface moderna e foco em usabilidade.

## Funcionalidades

- Cadastro de medicamentos (nome, lote, quantidade, validade, preço e fornecedor)
- Listagem completa do estoque
- Filtros por:
    - Todos os medicamentos
    - Medicamentos vencidos
    - Medicamentos que vencem nos próximos 30 dias
- Contadores em tempo real (total, vencidos e próximos do vencimento)
- Remoção de itens do estoque
- Design responsivo com tema escuro

## Tecnologias

- HTML5
- CSS3 (Glassmorphism + Gradientes)
- JavaScript (Vanilla)
- Font Awesome + Google Fonts
